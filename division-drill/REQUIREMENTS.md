# 나눗셈 연습 (Division Drill) - 요구사항 명세

## 개요

초등 3학년 나눗셈 연습을 위한 앱. `mad-minute`처럼 랜덤으로 생성된 문제 여러 개를 한 화면에 모두 표시하고, **몫**과 **나머지**를 입력한 뒤 **Submit**을 누르면 한 번에 채점된다. 시작 시 나눠지는 수와 나누는 수의 자리수, 문제 수를 드롭박스로 선택할 수 있다.

---

## 기능 요구사항

### 1. 시작 화면

- **나눠지는 수(피제수) 자리수** 드롭박스
  - 십의자리 (1~10)
  - 백의자리 (1~100)
  - 천의자리 (1~1000)
  - 만의자리 (1~10000)
- **나누는 수(제수) 자리수** 드롭박스
  - 일의자리 (1~9)
  - 십의자리 (1~10)
  - 백의자리 (1~100)
- **문제 수** 드롭박스: 5 / 10 / 20 (기본값 10)
- **Start 버튼**

두 드롭박스는 서로 독립적으로 선택하며, 나눠지는 수가 나누는 수보다 작게 뽑히는 조합(예: 피제수 십의자리 + 제수 백의자리)도 허용한다. 이 경우 몫 0, 나머지 = 나눠지는 수 자체가 정답이 된다.

### 2. 문제 화면 (전체 문제 한 화면에 표시)

- 상단바: 경과 시간(1초마다 증가하는 스톱워치, 표시 전용), 홈 버튼
- **제한 시간 없음**: mad-minute과 달리 시간 초과로 인한 자동 제출이 없음. 경과 시간은 계속 증가하기만 하며, 채점은 사용자가 Submit 버튼을 눌러야만 이루어짐
- Start 클릭 시 선택한 옵션에 맞춰 **문제 N개를 한 번에 랜덤 생성**, 문제 카드들을 그리드로 화면에 모두 표시 (숫자는 제출 전까지 변하지 않음)
- 각 문제 카드:
  - 문제 번호
  - **세로셈(장제법) 부호** 형태로 표시 (`84 ÷ 4 =` 같은 가로 텍스트가 아님)
    - 나누는 수(제수)는 왼쪽에, 나눠지는 수(피제수)는 왼쪽 세로선 + 위쪽 가로선으로 이루어진 괄호(부호) 안쪽 위에 표시 (초등 나눗셈 교과서에서 쓰는 세로셈 부호 모양)
  - 부호 아래에 `몫: [입력칸]  나머지: [입력칸]` 입력 필드 (숫자만 입력 가능)
- 문제 목록 맨 아래 **Submit 버튼**

### 3. 채점 (Submit)

- Submit 클릭 시 모든 문제를 한 번에 채점
  - 정답 조건: 입력한 몫이 `Math.floor(피제수 / 제수)`와 같고, 입력한 나머지가 `피제수 % 제수`와 같아야 함
  - 나누어떨어지는 문제는 나머지 입력값이 0이어야 정답 처리
  - 맞은 문제: 카드가 **녹색**으로 표시
  - 틀린 문제: 카드가 **빨간색**으로 표시되고 정답(몫/나머지)을 함께 보여줌
  - 몫/나머지 중 하나라도 비어있으면 오답 처리
  - 채점 후 입력 필드는 비활성화됨
- 나누는 수는 항상 1 이상으로 생성되므로 0으로 나누는 경우는 없음
- 화면 상단에 **맞은 개수 / 전체 문제 수** 점수와 총 소요 시간(스톱워치 정지) 표시
- **Reset 버튼** 표시 → 클릭 시 시작 화면으로 복귀, 자리수/문제 수 재선택 가능

### 4. 기록

- 채점 결과를 `localStorage`에 최근 10회까지 저장: 날짜, 자리수 설정, 점수, 소요 시간
- 결과 화면에 최근 기록 테이블 표시 (mad-minute 스타일)

## 레이아웃

- 문제 카드는 그리드로 배치 (문제 수에 따라 열 수 조정, 예: 2~5열)
- 필요 시 스크롤 가능

## 비기능 요구사항

- 단일 페이지 웹 앱, 별도 서버/빌드 불필요
- 데스크탑 기준, 반응형 고려 불필요
- UI 텍스트는 한국어 (`lang="ko"`)

---

## 용어

| 용어 | 설명 |
|------|------|
| 피제수 (나눠지는 수) | 나눗셈에서 나누어지는 수 (예: 84 ÷ 4 에서 84) |
| 제수 (나누는 수) | 나눗셈에서 기준이 되는 수 (예: 84 ÷ 4 에서 4) |
| 몫 | 나눗셈의 결과 (예: 84 ÷ 4 = 21에서 21) |
| 나머지 | 나누어떨어지지 않고 남는 수 (예: 85 ÷ 4 = 21...1에서 1) |
