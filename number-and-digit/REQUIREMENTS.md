# 수와 숫자 (Number & Digit) - 요구사항 명세

## 개요

"○에서 △까지의 수"라는 문제를 보고 **수의 개수**와 **숫자의 개수**를 각각 맞히는 연습 앱.
`division-drill`처럼 한 화면에 10문제를 모두 표시하고, 두 칸을 채운 뒤 **Submit**을 누르면 한 번에 채점된다.

### 용어 정의

| 용어 | 설명 |
|------|------|
| 수의 개수 | 범위 안에 들어있는 수의 총 개수 = `끝 - 시작 + 1` |
| 숫자의 개수 | 범위 안 모든 수를 적었을 때 쓰이는 숫자(자릿수) 총 개수 |

예시:

| 문제 | 수의 개수 | 숫자의 개수 |
|------|-----------|-------------|
| 1에서 8까지의 수 | 8 | 8 (한 자리 수 8개 × 1) |
| 10에서 22까지의 수 | 13 | 26 (두 자리 수 13개 × 2) |
| 256에서 263까지의 수 | 8 | 24 (세 자리 수 8개 × 3) |
| 98에서 103까지의 수 | 6 | 16 (98~99: 2개×2=4, 100~103: 4개×3=12) |

## 기능 요구사항

### 1. 시작 화면

- 게임 제목 + "수의 개수"와 "숫자의 개수"가 무엇인지 알려주는 짧은 설명(예시 1개 포함)
- **문제에 쓰일 수의 범위 설정** (난이도 조절 수단)
  - `최소값` 입력칸 (기본 1)
  - `최대값` 입력칸 (기본 100)
  - 모든 문제의 시작 수와 끝 수는 이 `[최소값, 최대값]` 안에서만 생성된다
  - 예: 1~20으로 두면 한 자리/두 자리만, 1~1000으로 두면 세 자리까지 섞여 나옴
- **Start 버튼**, 홈 버튼(`../`)
- 문제 수는 **10문제 고정** (별도 선택 없음)

#### 입력값 검증

| 조건 | 처리 |
|------|------|
| 최소값 < 1 또는 비어 있음 | 1로 보정 |
| 최대값 > 9999 | 9999로 보정 |
| 최대값 ≤ 최소값 | 시작하지 않고 안내 메시지 표시 |
| 범위 폭(최대값 - 최소값 + 1)이 3 미만 | 시작하지 않고 안내 메시지 표시 (문제를 만들 수 없음) |

마지막으로 사용한 최소값/최대값은 `localStorage`에 저장해 다음 방문 시 그대로 채워둔다.

### 2. 문제 화면 (10문제 한 화면)

- 상단바: 경과 시간(스톱워치, 표시 전용 · 제한 시간 없음), 설정한 범위 표시(예: `1 ~ 100`), 홈 버튼, Submit 버튼
- Start 클릭 시 10문제를 한 번에 랜덤 생성해서 그리드로 모두 표시 (제출 전까지 문제는 바뀌지 않음)
- 각 문제 카드:
  - 문제 번호
  - 문제 문장: `10에서 22까지의 수`
  - 입력 두 칸: `수의 개수 [   ]개` / `숫자의 개수 [   ]개` (숫자만 입력)
- Submit 버튼은 상단바에 배치 (division-drill과 동일)

### 3. 문제 생성 규칙

- 모든 수는 설정한 `[최소값, 최대값]` 안 (기본 1~100, 상한 9999)
- 끝 > 시작 (수의 개수는 항상 2개 이상)
- 한 범위에 포함되는 수의 개수(범위 폭)는 **3~30개**, 단 설정 범위가 좁으면 그에 맞춰 줄인다
- **자릿수 경계를 넘는 범위 허용**: 설정 범위 안에 자릿수 경계(9/10, 99/100, 999/1000)가 있으면
  한 세트 중 2~3문제는 의도적으로 그 경계를 넘는 범위로 출제한다. 경계가 없으면 전부 일반 문제로 채운다
- 같은 세트 안에서 동일한 범위가 중복되지 않게 하되, 설정 범위가 좁아 10개를 못 채우면 중복을 허용한다

### 4. 채점 (Submit)

- Submit 클릭 시 10문제를 한 번에 채점
- **문제 단위 채점(10점 만점)**: `수의 개수`와 `숫자의 개수` 두 칸을 **모두** 맞혀야 그 문제 정답
- 맞은 문제: 카드 **녹색** / 틀린 문제: 카드 **빨간색**
- 한 칸이라도 비어 있으면 오답 처리
- 틀린 문제에는 정답과 함께 **간단한 해설 한 줄** 표시
  - 같은 자릿수: `22 - 10 + 1 = 13개, 두 자리 수이므로 13 × 2 = 26개`
  - 경계를 넘는 경우: `103 - 98 + 1 = 6개, 98~99는 2개×2=4, 100~103은 4개×3=12 → 16개`
- 채점 후 입력 필드 비활성화, Submit 버튼 숨김 → **Reset 버튼** 표시
- 상단에 `맞은 개수 / 10` 점수와 총 소요 시간(스톱워치 정지) 표시

### 5. 기록

- 채점 결과를 `localStorage`에 최근 10회까지 저장: 날짜, **설정 범위(최소~최대)**, 점수, 소요 시간
- 결과 화면 하단에 최근 기록 테이블 표시 (mad-minute / division-drill 스타일)

## 레이아웃

- 문제 카드는 그리드 배치 (2~3열, `repeat(auto-fit, minmax(...))`)
- 필요 시 스크롤 가능

## 비기능 요구사항

- 단일 페이지 정적 웹앱, 빌드/서버 불필요
- 데스크탑 기준
- UI 텍스트는 한국어 (`lang="ko"`)
