# 언어 토글(한국어 / English) 추가

전체 사이트에 적용한 기능이며, 설계 전반은 루트의 `I18N_PLAN.md`에 정리되어 있다.

## 공통 방식

| 항목 | 결정 |
|------|------|
| 버튼 | 우측 상단 한 개 토글 (`🌐 English` ↔ `🌐 한국어`, 바뀔 언어를 표시) |
| 기본 언어 | 한국어 (브라우저 언어 자동 감지 없음) |
| 저장 | `localStorage`의 공용 키 `siteLang` — 다른 게임/런처와 선택이 공유된다 |
| 코드 | 게임별 자체 포함 (공유 `i18n.js` 없음): `I18N` 사전 + `t()` + `toggleLang()` + `applyLanguage()` |
| 정적 문구 | HTML `data-i18n` 속성 (마크업이 필요한 곳은 `data-i18n-html`) |
| 동적 문구 | 렌더 함수에서 `t()` 호출, 토글 시 다시 그림 |

## 이 게임에서 한 일

- 시작 화면(설명 박스 포함), 문제 문장, `수의 개수`/`숫자의 개수`, 정답 줄, 해설, 오류 문구, 기록 테이블까지 약 25개 문자열을 사전으로 이동
- 설명 박스는 `<b>` 강조가 있어 `data-i18n-html`(innerHTML 교체)로 처리
- 문제 문장은 `{start}`/`{end}` 자리표시자로 두고 강조용 `<span class="range-num">`을 끼워 넣는다
  - ko: `{start}에서 {end}까지의 수` / en: `Numbers from {start} to {end}`
- 해설도 언어별로 분리
  - ko: `22 - 10 + 1 = 13개, 두 자리 수이므로 13 × 2 = 26개`
  - en: `22 - 10 + 1 = 13 numbers, all 2-digit, so 13 × 2 = 26 digits`
  - 경계를 넘는 경우 ko: `98~99는 2개×2=4, 100~103은 4개×3=12 → 16개` / en: `98-99: 2×2=4, 100-103: 4×3=12 → 16 digits`
- 은/는 조사를 고르는 `topicParticle()`은 한국어 분기에서만 사용한다
- 오류 문구는 `state.error`에 키와 파라미터를 보관해, 표시 중에 언어를 바꿔도 함께 번역된다
- 채점 후 토글해도 점수·입력값·정답·해설이 유지되도록 `state.answers` 기반 재렌더 구조로 변경
