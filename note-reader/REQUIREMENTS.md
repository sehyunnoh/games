# 음표 읽기 - 요구사항 명세

## 개요

오선보에 랜덤으로 나오는 음표를 보고, 오른쪽 피아노 건반을 클릭해서 어떤 음인지 맞추는 무제한 연습 앱. 피아노를 배우는 아이의 양손(높은음자리표/낮은음자리표) 악보 읽기 연습이 목적.

---

## 기능 요구사항

### 1. 시작 화면

- **손 모드** 선택 (라디오 버튼 형태)
  - 오른손만 (높은음자리표)
  - 왼손만 (낮은음자리표)
  - 혼합 (문제마다 랜덤)
- **음 범위** 선택
  - 오선 안쪽만
  - 가운데 도(middle C) 포함 확장 (덧줄 포함)
- **Start 버튼**
- 최고 연속 정답(streak) 기록 표시 (있다면)

### 2. 연습 화면 (좌우 분할)

- **왼쪽: 오선보**
  - 선택된 손 모드에 맞는 자리표(높은음자리표 𝄞 / 낮은음자리표 𝄢) 표시
  - 혼합 모드는 문제마다 자리표가 바뀜
  - 오선 5줄 + 음표 1개 (범위에 따라 덧줄 포함)
- **오른쪽: 피아노 건반**
  - 흰건반 + 검은건반을 실제 피아노처럼 배치 (검은건반은 클릭 불가, 시각적 참고용)
  - 흰건반에는 음이름을 표시하지 않음 (건반 위치와 악보 위치를 스스로 연결하는 것이 학습 목표)
  - 가운데 도 건반에는 작은 점 표시로 기준점 제공
  - 건반 범위는 선택한 손 모드/음 범위에 따라 동적으로 결정 (필요한 음보다 살짝 여유 있게)
- **상단바**
  - 연속 정답(streak), 누적 정답 수 / 전체 문제 수(정답률)
  - 홈 버튼

### 3. 채점 (무제한 연습)

- 건반 클릭 시 즉시 채점 (제출 버튼 없음)
- **정답**: 음표와 클릭한 건반이 초록색으로 짧게 표시 → 자동으로 다음 문제
- **오답**: 클릭한 건반은 빨간색, 정답 건반은 노란색으로 표시 → 잠시 후 다음 문제
- 직전 문제와 같은 음이 연속으로 나오지 않도록 함
- 최고 연속 정답 기록은 `localStorage`에 저장, 새 기록 갱신 시 갱신

### 4. Reset / 설정 변경

- 연습 화면에서 홈 버튼 또는 별도 "설정" 버튼으로 시작 화면으로 돌아가 모드를 바꿀 수 있음

---

## 비기능 요구사항

- 단일 페이지 웹 앱, 별도 서버/빌드 불필요
- 자연음(A~G)만 사용, 임시표(#, ♭)는 다루지 않음 (grade 3 수준에 맞춤)
- 데스크탑 기준, 반응형은 고려하지 않음
